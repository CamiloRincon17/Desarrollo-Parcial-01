# 🏍️ MotoMax - Tu Aliado en Dos Ruedas

## 🚀 Proyecto Completamente Optimizado

MotoMax es una aplicación web moderna y completamente funcional para la venta de motocicletas deportivas, de aventura y off-road. El proyecto ha sido completamente optimizado con las mejores prácticas de desarrollo web moderno.

## 🚀 Cómo Usar

1. **Abrir** `index.html` en un navegador moderno
2. **Login** con credenciales: `admin` / `moto2025`
3. **Explorar** el catálogo de motos
4. **Buscar** motos específicas
5. **Ver detalles** haciendo clic en las tarjetas
6. **Agregar a favoritos** desde el modal
7. **Contactar** vía WhatsApp

## 🔧 Personalización

### **Agregar Nuevas Motos**
Edita `data/producto.json` y agrega nuevas motos en las categorías existentes.

### **Modificar Estilos**
Usa las variables CSS en `:root` para cambiar colores y estilos globalmente.

### **Agregar Funcionalidades**
Los archivos JavaScript están modularizados para fácil extensión.
